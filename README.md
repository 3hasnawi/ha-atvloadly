# Cinema iQ add-ons for Home Assistant

| Add-on | |
|---|---|
| [atvloadly](./atvloadly) | Sideload and auto-refresh apps on Apple TV (wraps [bitxeno/atvloadly](https://github.com/bitxeno/atvloadly)) |

## التثبيت

1. في Home Assistant: **الإعدادات ← الإضافات ← متجر الإضافات**، ثم القائمة (⋮) ← **المستودعات**.
2. أضف: `https://github.com/3hasnawi/ha-atvloadly`
3. ابحث عن **atvloadly** وثبّته وشغّله، ثم افتح واجهته على المنفذ 5533.

The add-on is a thin wrapper: atvloadly itself is © bitxeno, GNU AGPL v3.
